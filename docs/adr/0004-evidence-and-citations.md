# ADR 0004：按需证据视图、prompt 引用与显式记忆修改

状态：接受。

## 决策

不要再保存一份完整会话历史。原生 transcript 按需读取、在内存中转换为模型
输入；只持久化摘要、来源元数据、任务状态、引用收据和有限运行状态。
hooks 是唤醒／注入入口，不是全量聊天镜像的数据源。媒体默认保留类型和路由
信息，不复制图片字节，不声称已经理解只存在于附件里的内容。

引用由 prompt 要求输出。通过外置程序读取已完成的 assistant 输出并幂等计数，
不要求先修改 Kimi 引擎或实现 Codex 式引用 UI。前台文件访问遥测不能替代
实际引用计数。来源 ID 使用 Kimi 原生标识，不增加没有必要的 UUID 映射。

只使用注入的总摘要时不强制引用；只有实际读取并使用来源摘要才引用它。不得
为了制造计数或获取引用标识强迫模型做额外无意义的检索。

显式 remember/forget/correction 请求写入持久化的小型 notes，由合并应用。
前台不得直接编辑生成文件；排队成功不能说成已完成全部遗忘。

## 不可接受的捷径

解析失败不是空历史。重复 replay 或 fork 复制的历史不是新的记忆使用。缺少
准确引用完成时间时，不能用今天的扫描时间为旧记忆续期。

不能让不可信的日志／记忆／note 内容启动任意 shell、访问外部网络或修改
用户项目。可增加更严格的安全验证，但不要称模型合并已经具备事实级形式化保证。
