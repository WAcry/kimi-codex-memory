# ADR 0003：借用或按需启动辅助服务，兼容版本不等于同版本号

状态：接受。兼容策略与 ADR 0005、0006 一致。

## 服务决策

用户只使用 CLI 时，允许 worker 启动 Kimi 自带的 Web/API 服务，不要求用户
改用浏览器。优先借用已存在且经过验证的同-home 服务，否则启动自己的本机
辅助实例。辅助端口避开用户默认 Web 端口范围；不打开浏览器，不启用 Remote
Control，不绕过认证，不改用户全局配置。

只能关闭本项目亲自启动并确认所有权的进程，不能关闭、升级、重启用户的实例。
读取完成后回收辅助实例；未来允许经测量增加有限空闲保留，但不能未经决定
变成无限常驻、每个 session 一个服务。

## 兼容决策

memory 的发布版本与 Kimi 的发布版本独立。新 Kimi 版本直接尝试当前
契约；实际接口／数据校验失败才暂停相应处理，不设产品版本白名单。

辅助服务使用用户当前安装的 Kimi。健康连接可以完成当前批次，自有进程
结束后下次自然采用当前安装。不能自动安装、升级或回退另一版 Kimi。
