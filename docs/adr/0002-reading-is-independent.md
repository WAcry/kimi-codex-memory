# ADR 0002：已有记忆读取不能依赖生成成功

状态：接受；这是用户实施前再次强调的最高优先级要求。

## 决策

以下故障不得关闭提示词提供、已发布摘要注入、或前台按需 rg/Read：

- 原生 Web 不可用，或 Kimi API 版本／结构不兼容。
- 提取或合并模型失败，配额不足，模型凭据过期。
- 生成配置解析失败、生成关闭、生成数据库损坏。

读路径的配置、加载依赖、执行入口和错误传播必须与生成路径分离。可验证的
验收方式包括主动使 worker 模块无法导入、破坏生成配置／SQLite，再运行真实
hook 入口验证已发布记忆仍被注入。

用户可以通过独立 reader 设置主动关闭自动注入。不要把“生成暂停”等同于
“用户不希望读取已有记忆”。不要为了配置统一而取消这项隔离。

## 失败时的行为

保留上一次成功发布的文件；生成错误进入独立状态与诊断，不能成为普通对话的
阻断理由，也不应每轮刷屏。读取已有记忆不要求联网或打开 SQLite。

一次 hook 的状态记账失败，不应让本次可用的提示词内容被丢弃。后台重试、
版本门禁和服务启动必须在读路径之外。
