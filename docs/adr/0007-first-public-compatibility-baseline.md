# ADR 0007：1.0.0 是首个正式兼容基线

状态：接受。来源：用户明确确认开发阶段没有真实用户，要求删除发布前
兼容分支并正式发布 1.0.0；兼容责任从这个版本开始。

## 首版清理

不自动发现/迁移旧产品目录，不兼容开发版 current 符号链接、直接目录
摘要、旧配置键、旧数据库迁移或旧注入状态。只有现在的产品名称、默认
目录、配置和存储布局。删除相关的迁移测试与过期说明；历史留在 Git，
不是用户运行时必须承担的代码。清理代码不意味着删除用户磁盘目录。

Kimi 的实际契约容错、OAuth 源码和 Windows 平台适配不是本项目开发版
兼容，不因这次清理移除。reader 与生成隔离、发布恢复也继续保留。

## 从正式用户开始承担兼容

1.0.0 之后，配置、已发布记忆、notes、引用收据和上下文检查状态都是
用户数据。patch/minor 不无提示破坏这些已公布的契约；真正的破坏性
变更需要 major、明确说明和数据迁移/保留方案。

产品版本与 SQLite/schema、发布文件格式独立。首版 DB schema=1，发布
指针/manifest format=1；Codex memory v2 的摘要首行仍然按原版写 v1。
不同概念的版本号不相互推导。

当前没有先验迁移框架或空迁移步骤。以后结构改变时按真实需要实现，
从已发布基线测试升级、备份、幂等和中断恢复。未知新 schema 不回退
写入，不能恢复旧备份来覆盖用户新数据；在文件格式仍可读时 reader
继续工作。已发布测试样例保留不变，用来检测后续不小心破坏契约。

## 宿主与发布

插件保持独立版本；不要求与 Kimi 版本相同，不主动升级 Kimi。新增
Kimi 产品版本继续尝试实际 API，失败只影响相关生成。更新插件走原生
Marketplace，程序安装与数据目录分离。平台验证全部通过才发布。
