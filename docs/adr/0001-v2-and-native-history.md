# ADR 0001：只实现 memory v2，优先由宿主解释历史

状态：接受。来源：用户连续设计讨论与首次实施授权。

## 决策

本项目直接实现 Codex memory v2 的产品语义。第一版不支持 memory v1、双写、
旧版 Kimi 协议迁移、诊断 ZIP 导入，或自行探索 raw JSONL 的运行时模型。

会话历史来自当前 Kimi 原生 transcript API。宿主负责重建自己的日志；本项目
负责证据筛选、提取、合并、引用统计和生命周期。原生服务能够返回当前结构的旧
会话可以使用；这不等于本项目维护旧协议适配。

不用向量数据库或嵌入检索替代本地文件读取。前台 agent 可直接利用 rg/Grep/Read
按需查阅摘要与会话证据。

截断比例、token 与字节常量不是逐值兼容目标。允许利用 Kimi 的现有估算方法，
但必须保留“真实人类要求与纠正优先于工具噪声”的证据选择原则。

## 原因与约束

用户重视机制接近原版，但不希望兼容分支、重复历史存储和自主 schema 猜测
增加维护负担。不要因一次 API 变动就悄悄加入完整 JSONL reader 或启用 v1。
确实需要改变这项范围时，应作为明确的产品决定，而不是修复顺手扩大范围。
