# ADR 0010：局部失败隔离与复用原生模型请求

状态：接受。来源：用户报告删除/归档来源导致整批暂停，要求审查读取和
生成期间的并发变化，修复后发布补丁。用户补充 Kimi thinking 模型的
提取 JSON 错误，要求评估复用原生底层请求能力，不能猜测输出或盲目把
推理通道内容当成记忆结果。

## 故障范围

不存在的会话、单个坏历史、分页中变更、某次提取输出错误、个别坏 note
属于局部故障。保留正常会话的引用收据和摘要，继续其他提取和可安全
执行的合并。状态用 degraded 与有限诊断表达，不伪装全部成功。

引用覆盖不足时，保留上次成功选择的来源，不据此过期或淘汰它们；允许
非淘汰式合并纳入正常新来源和明确 notes。容量已满时可以保存新摘要
但暂不进入选集。全局数据库损坏、写权限、租约失效、无有效合并输出
不能靠吞错写坏数据：暂停 writer，reader 仍独立。

只有明确 session-specific 缺失才确认已删除。HTTP 200/code 40401、
HTTP 404/410 被分类为来源缺失，401/403/429/500/超时不是删除证明。
归档不等于删除，仍可同步已有引用；不为归档会话新增提取。

## 变化时机

读取一份来源完整快照前若发生删除/变化，跳过并重试/确认缺失。快照
通过后不在模型步骤重新读取原会话；此后关闭/归档/删除不阻断快照
生成。删除原聊天不自动撤销已有记忆，显式忘记请求是另外的路径。

模型运行中新 hook 到达，不再禁止所有发布，只保护真正会移除来源的
发布与 TTL 清理。完整 source_updated_at/version 与有效 owner 仍被
检查。允许真实活动和后台有进展，不引入实时宿主事务或长期锁。

## 原生请求边界

使用固定 Kimi 源码中的 Chat/Responses/Anthropic requester、思考配置、
消息累计和回放，而不是继续维护独立 Python wire codec。Python 保留
任务、配置/认证适配、预算、输出 schema 和受限工具；JS 只做模型请求，
不启动 agent/session，不加载用户工具或创建可再次总结的聊天记录。

原生模块原样复制并记录 hash，SDK 与依赖锁定、许可证随包，使用已安装
Kimi 的 Node 运行时，不要求用户安装另一份 Node。升级 Kimi 不会静默
替换这些固定源码；以后更新仍通过插件发布和三协议回归。

结果通道由后续 ADR 0011/0012 规定：优先最后一个合法结果工具，所有
调用都不可用时才读取 final text 中最大的合法结果 JSON。不修复 JSON、
不挪用 reasoning，不接受未完成流。格式错误只失败这一条来源，不擦掉旧摘要。
新 requester 版本为旧失败任务重新提供一次正常重试预算，不重做
成功结果；版本相同不会反复重置失败次数。

没有真实返回体，不能证明用户这次错误由思考通道造成，也不能用本地
脚本模型声称任意网关配置完全等同于 Kimi 全应用。复用的是底层请求
协议、思考/工具语义，不是复制整套运行服务。
